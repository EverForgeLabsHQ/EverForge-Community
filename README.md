# EverForge Community

Welcome to the community space for **EverForge Labs**. We build AI-powered software, practical workflow automation, and custom 3D-printed solutions.

Visit [everforgelabs.com](https://everforgelabs.com/) to learn about our work, explore [3D prints](https://everforgelabs.com/prints/), or [contact us](https://everforgelabs.com/contact/).

## Get involved

- Open an issue to suggest an idea, ask a project question, or report a reproducible problem.
- For a proposed change, open or discuss an issue first when useful, then submit a pull request from your fork.
- Explain what your change does, why it helps, and how you checked it. Maintainers review changes before merging them.
- Keep credentials, private customer information, and proprietary source out of public issues and pull requests.

This is a starter community repository. Selected software and contribution instructions will be added as they become available.
